# UI引き継ぎメモ

現在の機能・操作・実装範囲は、リポジトリ直下の [README.md](../README.md) に集約しています。

タブは「気温別コーデ・ホーム・今日のひろば」の3つです。ホームの写真診断ボタンから標準写真ピッカーを直接開き、写真選択直後に診断画面へ、ホームの場所名以外の提案カードを押すと固定プロンプトを設定して提案画面へ進みます。場所名のタップは選択シートを開くだけで、提案は実行しません。

今日のひろばは、タブを押すたびに場所選択シートを開き、選択した場所の口コミだけを表示します。閲覧場所はホームとは独立しています。

フロントエンド内の操作結果は `LayeRoomViewModel.latestAiRequest` です。写真または固定プロンプト「今日の服装を提案して」と、選択場所・室温・金沢の気温を受け渡します。サーバーAPIの定義、実際の送信・AI処理・保存は行っていません。
